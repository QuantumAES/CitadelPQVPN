# Снимки экрана для README

Файлы здесь — настоящие снимки, снятые с тестового профиля и тестового exit'а. На них
ссылается корневой `README.md`: переименование сломает картинки на главной странице проекта,
поэтому пересъёмку кладите под тем же именем.

| Файл | Что снято | Минимальный размер |
|---|---|---|
| `android-split.png` | Экран раздельного туннелирования: список приложений и/или назначений | 540×1170 |
| `linux-gui.png` | Окно Linux-клиента в состоянии «подключено» | 900×1400 |
| `linux-cli.png` | TUI `citadel-cli`: статус, профили, журнал, kill-switch | 1280×800 |
| `windows-connected.png` | Окно Windows-клиента; хорошо, если в кадр попадёт значок в трее | 660×1200 |

Главный экран с поднятым туннелем показан снимками Linux и Windows; отдельный
`android-connected.png` из README убран — он повторял ту же карточку статуса третий раз.

Крупнее — можно и нужно: GitHub масштабирует изображение под ширину колонки, поэтому
скриншот с ретины выглядит заметно лучше. Формат — PNG.

## О чём стоит помнить, снимая VPN-клиент

Кадр главного экрана содержит рабочие данные: **адрес exit-сервера, имя профиля, имя устройства,
идентификаторы абонентов, выданный адрес в туннеле**. В README они попадают навсегда и в тот же
день оказываются в поисковых индексах и зеркалах.

Поэтому снимайте с тестового профиля и тестового exit'а, а не с боевого; экран «Абоненты»
(там метки живых людей) в README не нужен вовсе. Замазанный прямоугольник поверх адреса —
плохая защита: он читается по остальным элементам интерфейса и по контексту. Проще
подготовить профиль с заведомо публичными значениями.
